## 按使用场景选：三类人该买，两类人别买

付费版值不值，取决于你一年要处理多少张图。

**该买的情况：**

第一种是工作里要往群里发截图的人。订单号、客户手机号、内部报价都在图上，手动涂一条条太慢，AI 识别能省一半时间。截图里带着软件图标水印，发给客户也不好看，这个恰好是付费版才能关掉的。

第二种是需要给证件照加水印的人。租房、入职、办业务经常被要求提供身份证照片，加上「仅用于某某业务」的文字水印，能少一层被挪用的风险。文字水印的大小、间距、透明度和旋转角度都能调，压上去不会盖住关键信息。

第三种是做二手交易、发社交动态前习惯遮脸遮昵称的人。这类操作频次高，工具顺不顺手直接影响你还用不用。

**不用买的情况：**

一个月发不了三张图，手动用微信自带的涂鸦就能解决，没必要为它装个 App。

用安卓手机的也别看了，DAMA 是 iOS 专用，安卓端没有对应版本。主要在电脑上批量处理图片的同样不合适，这是手机端工具，几十上百张图在手机上点效率很低。
